# Python Offensive Security Course

This repository contains all the materials and scripts developed during S4vitar's Offensive Python course. The content is structured to progress from basic Python concepts to advanced offensive security tools and scripts.

## Repository Structure

### Python Fundamentals Section
The repository is divided into two main sections. The first section covers Python fundamentals and includes:

#### Basic Elements and Data Types
Comprehensive coverage of Python basics, including:
- String formatting and manipulation
- Functions and lambda expressions
- Exception handling
- Data structures (lists, tuples, sets, dictionaries)
- Object-Oriented Programming concepts

#### Standard Library and Tools
Implementation of core Python functionalities:
- Date and time handling
- Regular expressions
- File and directory management
- Network programming (basic client-server implementations)

#### Common Libraries
Practical exercises with essential Python libraries:
- OS and sys modules for system interaction
- Requests and Urllib3 for HTTP operations
- Threading and multiprocessing for concurrent programming

#### GUI Development
Various examples of graphical interfaces using:
- Tkinter implementations (calculator, text editor)
- CustomTkinter for modern UI elements

### Offensive Python Section
The second section focuses on offensive security tools and includes:

#### Network Scanning Tools
- ARP scanner implementation
- ICMP scanner for network discovery
- Port scanner for service enumeration

#### Network Sniffing Tools
- DNS traffic analyzer
- HTTP traffic capture
- HTTPS traffic interception

#### Network Spoofing Tools
- ARP spoofing implementation
- DNS spoofing capabilities
- HTTP traffic manipulation

#### Advanced Tools
- Forward Shell implementation with Docker support
- Keylogger with logging capabilities
- MITM proxy implementations

#### Utility Scripts
- MAC address manipulation tools
- IP forwarding utilities
- Various network configuration scripts

## Documentation
